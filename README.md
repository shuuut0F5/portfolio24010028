# Shuto Fukuda Portfolio

このリポジトリのメインコンテンツは、福田修斗のポートフォリオサイト **`index.html`** です。プロフィール、制作実績、問い合わせフォームを1ページにまとめています。

## `index.html` の内容

ページは次のセクションで構成されています。

### Home

名前、ポートフォリオタイトル、インフラエンジニア志望であることを掲載しています。

### About

プロフィールに加え、志望職種、学習・制作で取り組んでいる技術、入社後に活かしたい力を紹介しています。

### Works

2つのインフラ構築プロジェクトを掲載しています。各カードを選ぶと、詳細をモーダルで確認できます。

- **Terraform × LXD** — LXD上にNginxコンテナを3台構築し、HAProxyでラウンドロビン負荷分散を行う構成
- **Docker Compose × Ansible** — Nginx、PHP-FPM、MySQL、Redisのマルチコンテナ構成と、Ansibleによるデプロイ自動化

プロジェクト詳細には、アーキテクチャ図、構成ファイル例、構築手順、トラブルシューティング、制作を通じた学びを掲載しています。

### Contact

Formspreeを利用した問い合わせフォームです。送信状況はページ上に表示されます。

## ページの機能

- 固定ヘッダーから各セクションへスムーズに移動
- プロジェクト詳細の表示・終了（閉じるボタン、背景クリック、Escキー）
- 詳細内のタブ切り替えと、トラブルシューティング項目の展開
- 設定例・コマンド例のクリップボードへのコピー
- 画面幅に応じたレイアウト調整
- ページの最終更新日の表示

## 表示方法

ビルドや依存パッケージのインストールは不要です。`index.html`をブラウザーで開いてください。

ローカルサーバーで表示する場合は、リポジトリのディレクトリで次を実行し、`http://localhost:8000`にアクセスします。

```bash
python -m http.server 8000
```

## 実装

HTML、CSS、JavaScriptはすべて`index.html`に含まれています。Google FontsとUnsplashの画像を利用しているため、これらの外部リソースの読み込みにはインターネット接続が必要です。

問い合わせフォームの送信先は、`index.html`内のContactフォームにある`action`属性で設定しています。フォームを利用する場合は、Formspree側の設定と送信先URLを確認してください。

## ファイル構成

- **`index.html`** — ポートフォリオサイト本体（ページ内容、スタイル、動作）
- **`README.md`** — このページの概要と表示方法
