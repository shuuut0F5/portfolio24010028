# Shuto Fukuda | Portfolio

インフラエンジニアを目指す福田修斗のポートフォリオサイトです。プロフィール、制作したインフラプロジェクト、問い合わせフォームを1ページにまとめています。

## ページの内容

- **About**: プロフィール、志望職種、学習中の技術、仕事で活かしたい力
- **Works**: 2つのインフラ構築プロジェクト
  - **Terraform × LXD**: LXD上にNginxコンテナを3台構築し、HAProxyでラウンドロビン負荷分散
  - **Docker × Ansible**: Nginx・PHP-FPM・MySQL・Redisのマルチコンテナ構成と、Ansibleによるデプロイ自動化
- **プロジェクト詳細**: 概要、構成図、設定例、構築手順、トラブルシューティング、学び
- **Contact**: Formspreeを利用した問い合わせフォーム

## 表示・操作

- ヘッダーのナビゲーションから各セクションへ移動
- Worksのカードを選択してプロジェクトの詳細を表示
- 詳細画面ではタブ切り替え、トラブルシューティング項目の展開、コード例のコピーが可能
- Escキーまたは閉じるボタンでプロジェクト詳細を終了
- 画面幅に応じてレイアウトを調整
- フッターにページの最終更新日を表示

## 表示方法

ビルドやパッケージのインストールは不要です。`index.html`をブラウザーで開くと表示できます。

ローカルサーバー経由で確認する場合は、プロジェクトのディレクトリで次を実行し、ブラウザーで `http://localhost:8000` を開きます。

```bash
python -m http.server 8000
```

## 使用技術・外部サービス

- HTML、CSS、JavaScript（`index.html`内に記述）
- Google Fonts（Fira Code、Playfair Display、Zen Kaku Gothic New、Lato）
- Unsplashの画像
- Formspree（問い合わせフォームの送信先）

フォントと画像の読み込み、およびフォーム送信にはインターネット接続が必要です。フォーム送信先を変更する場合は、`index.html`内のフォームの`action`属性を更新してください。

## ファイル

- `README.project.md`: Terraform × LXDのインフラ構築プロジェクトについての説明。
