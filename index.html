プロジェクト概要

このプロジェクトは、Terraform を使用して LXD コンテナインフラストラクチャを Infrastructure as Code で管理するシステムです。 手動設定を排除し、再現可能で スケーラブルな環境を実現します。

Terraform のモジュール化により、複数の環境（開発、ステージング、本番）を効率的に管理し、 変更の追跡と監査が容易になります。
