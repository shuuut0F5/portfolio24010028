Docker Compose × Ansible によるマルチコンテナ Web インフラ構築

作成者：shuto — 実運用に近い構成管理フローをローカル環境で再現したプロジェクト

プロジェクト概要

このプロジェクトでは、Docker Compose と Ansible を組み合わせて、 Web サーバー・アプリケーションサーバー・データベース・キャッシュサーバーからなるマルチコンテナ Web インフラ を構築しました。 開発環境から本番環境へのデプロイまでを自動化し、構成管理ツールによる統一的な運用フローを実証しています。

構成図（再現したインフラ）

  • Nginx（Reverse Proxy / Port 80）
  • PHP-FPM（Application Server / Port 9000）
  • MySQL（Database / Port 3306）
  • Redis（Cache Layer / Port 6379）

実現したこと

1. Docker Compose によるマルチコンテナ構成のコード化

  • Web・アプリ・DB・キャッシュの 4 コンテナを Compose で一括管理。
  • コンテナ間ネットワーク、ボリューム永続化、依存関係をコード化。
  • docker compose up -d だけで本番に近い構成を自動構築。
services:
  nginx:
    image: nginx:latest
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./app:/var/www/html
    depends_on:
      - php

  php:
    build:
      context: .
      dockerfile: Dockerfile
    expose:
      - "9000"
    volumes:
      - ./app:/var/www/html

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: rootpass
      MYSQL_DATABASE: appdb
    volumes:
      - mysql_data:/var/lib/mysql

  redis:
    image: redis:latest
    ports:
      - "6379:6379"

2. Ansible による構成管理・自動デプロイ

  • Docker のインストール、Compose の配置、サービス起動を Ansible で自動化。
  • 複数ホストへの横展開が可能な構成管理フローを実装。
  • 本番運用で使われる「構成の再現性」「自動化」「一括適用」を体験。
- name: Deploy multi-container web infrastructure
  hosts: web
  become: yes
  tasks:
    - name: Install Docker
      apt:
        name: docker.io
        state: present

    - name: Start Docker Compose
      community.docker.docker_compose_v2:
        project_src: /home/user/project
        state: present

3. Nginx → PHP-FPM → MySQL → Redis の連携構築

  • Nginx の FastCGI 設定で PHP-FPM にリクエストをルーティング。
  • PHP から MySQL に PDO 接続し、DB 操作を確認。
  • PHP に Redis 拡張をビルドし、キャッシュサーバーとの連携を実装。
  • Web アプリケーションの基本構成をコンテナで完全再現。

4. Dockerfile による PHP 拡張のビルド

  • Redis 拡張を pecl でインストールし、PHP-FPM に組み込み。
  • 本番環境で必要な拡張を Dockerfile で管理する方法を習得。
FROM php:8.2-fpm
RUN apt-get update && apt-get install -y libssl-dev \
    && pecl install redis \
    && docker-php-ext-enable redis

5. 開発〜本番を意識した構成管理フローの実装

  • ローカルで構築 → Ansible でデプロイ → コンテナ起動まで自動化。
  • 実運用に近い「構成の統一管理」「自動デプロイ」を体験。
  • クラウドインフラの基礎（IaC・構成管理・マルチコンテナ）を習得。
