Terraform × LXD で「完全無料 EC2 管理体験」を作るまでのまとめ

このページは、Terraform と LXD を使って、完全無料で EC2 とほぼ同じ管理体験を構築した手順と、 途中でつまずいたポイント・解決方法をまとめたものです。

1. Terraform の動作確認

成功 
terraform -version
which terraform

Terraform がインストールされていることを確認。最新版ではない警告は出たが、動作には問題なし。

2. VirtualBox プロバイダーでの失敗と方針転換

つまずき

VirtualBox 用の Terraform プロバイダー hashicorp/virtualbox は 公式レジストリに存在しないため、terraform init が失敗。

そこで、公式プロバイダーがある LXD を使う方針に切り替えた。 これにより、完全無料かつ安定した「EC2 風インスタンス管理」が可能になった。

3. LXD のインストールと初期化

成功 
sudo apt install -y lxd
sudo lxd init

初期化時にストレージプール名 default が既に存在していたため、 新しい名前（例：default2）を入力して設定を完了。

4. Terraform 設定ファイル vm.tf の作成

成功

デスクトップに vm.tf を作成：

terraform {
  required_providers {
    lxd = {
      source  = "terraform-lxd/lxd"
      version = "1.7.0"
    }
  }
}

provider "lxd" {}

resource "lxd_container" "test" {
  name  = "terraform-test"
  image = "ubuntu:22.04"
}

これで Terraform が LXD コンテナ（EC2 風インスタンス）を管理できるようになる。

5. terraform init（プロバイダーの取得）

成功 
cd ~/デスクトップ
terraform init

LXD プロバイダー terraform-lxd/lxd が正常にインストールされ、初期化完了。

6. terraform apply でのエラーと解決

6-1. 権限エラー（permission denied）

つまずき 
dial unix /var/snap/lxd/common/lxd/unix.socket: connect: permission denied

原因：siwuser ユーザーが LXD のソケットにアクセスする権限を持っていなかった。

解決コマンド

sudo usermod -aG lxd siwuser
sudo reboot

6-2. インスタンス名の重複エラー

つまずき 
This "instances" entry already exists

原因：同じ名前のコンテナ terraform-test が既に LXD に存在していた。

解決コマンド

lxc list
lxc delete terraform-test --force

6-3. 再度 terraform apply（成功）

成功 
terraform apply
# Enter a value: yes

Apply complete! Resources: 1 added, 0 changed, 0 destroyed.

これで terraform-test コンテナが正常に作成・起動し、EC2 インスタンスと同じ状態になった。

7. EC2 風の操作：一覧・ログイン・削除

7-1. インスタンス一覧（EC2 のインスタンス一覧と同じ）

lxc list

7-2. インスタンスへログイン（EC2 の SSH と同じ）

lxc exec terraform-test -- bash

これでコンテナ内の Ubuntu に入って、通常の Linux 操作が可能。

7-3. インスタンス削除（EC2 の terminate と同じ）

Terraform で削除：

terraform destroy
# Enter a value: yes

LXD で直接削除：

lxc delete terraform-test --force

8. つまずきポイントと解決コマンド一覧（総まとめ）

VirtualBox プロバイダーが取得できない

問題

公式に存在しないため、LXD に切り替え。

sudo apt install -y lxd
sudo lxd init

LXD ソケットへの権限不足

問題 
dial unix /var/snap/lxd/common/lxd/unix.socket: connect: permission denied

解決

sudo usermod -aG lxd siwuser
sudo reboot

コンテナ名の重複

問題 
This "instances" entry already exists

解決

lxc list
lxc delete terraform-test --force

ストレージプール名の重複

問題 
The requested storage pool "default" already exists. Please choose another name.

解決

default2

9. 最終的にできるようになったこと

  • Terraform の基本操作（init / apply / destroy）
  • LXD のインストール・初期化・権限設定
  • コンテナ（EC2 風インスタンス）の作成・起動・ログイン・削除
  • エラーの原因を読み取り、適切なコマンドで解決する力

これらはそのまま AWS 本番環境でも通用するインフラの基礎スキルになっている。
