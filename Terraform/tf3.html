Terraform × LXD で複数コンテナ Web サーバーを構築した記録

ローカル環境で EC2 風インフラを再現し、3 台の Web サーバーを構築・管理したプロジェクト

プロジェクト概要

このプロジェクトでは、クラウドを使わずに Terraform × LXD を組み合わせて、 複数の Ubuntu コンテナを Web サーバーとして構築・管理する環境を作成しました。 目的は、AWS EC2 や Auto Scaling の概念をローカル環境で再現し、 インフラ構成管理（IaC）の基礎を身につけることです。

使用技術

  • Terraform（LXD プロバイダー）
  • LXD（コンテナ仮想化）
  • Ubuntu 22.04 コンテナ
  • nginx（Web サーバー）

手順の流れ

1. LXD のインストールと初期化

成功 
sudo apt install -y lxd
sudo lxd init

ストレージプール名の重複があったため、新しい名前（例：default2）を設定して初期化しました。

2. Terraform 設定ファイル vm.tf の作成（複数コンテナ構成）

成功 
terraform {
  required_providers {
    lxd = {
      source  = "terraform-lxd/lxd"
      version = "1.7.0"
    }
  }
}

provider "lxd" {}

resource "lxd_container" "web" {
  count = 3

  name  = "web-${count.index + 1}"
  image = "ubuntu:22.04"
}

count = 3 により web-1 / web-2 / web-3 の 3 台のコンテナを自動作成する構成にしました。

3. 古い単一コンテナ構成からの移行

成功 
# 旧コンテナの削除
lxc delete terraform-test --force

# Terraform の状態から旧リソースを削除
terraform state rm lxd_container.test

単一コンテナ terraform-test を削除し、Terraform の状態もクリーンにしてから複数コンテナ構成へ移行しました。

4. terraform apply による複数コンテナ作成

成功 
terraform apply
# → web-1, web-2, web-3 が作成される

lxc list
# NAME   STATE   IPV4
# web-1  RUNNING ...
# web-2  RUNNING ...
# web-3  RUNNING ...

5. 各コンテナにログイン

成功 
lxc exec web-1 -- bash
lxc exec web-2 -- bash
lxc exec web-3 -- bash

それぞれのコンテナ内で Ubuntu 22.04 が正常に動作していることを確認しました。

6. nginx のインストール（コンテナ内部）

成功 
sudo apt update
sudo apt install -y nginx

7. ホストから各コンテナへのポートフォワード設定

成功 
lxc config device add web-1 http proxy \
  listen=tcp:0.0.0.0:8081 \
  connect=tcp:127.0.0.1:80

lxc config device add web-2 http proxy \
  listen=tcp:0.0.0.0:8082 \
  connect=tcp:127.0.0.1:80

lxc config device add web-3 http proxy \
  listen=tcp:0.0.0.0:8083 \
  connect=tcp:127.0.0.1:80

これにより、ホスト側から http://localhost:8081 / 8082 / 8083 経由で 各コンテナの nginx にアクセスできるようになりました。

8. Web コンテンツの変更による動作確認

成功 
# web-1 内
echo "This is web-1" | sudo tee /var/www/html/index.html

# web-2 内
echo "This is web-2" | sudo tee /var/www/html/index.html

# web-3 内
echo "This is web-3" | sudo tee /var/www/html/index.html

# ホスト側から確認
curl http://localhost:8081  # → This is web-1
curl http://localhost:8082  # → This is web-2
curl http://localhost:8083  # → This is web-3

それぞれ異なるメッセージが表示されることで、 3 台の Web サーバーが独立して動作していることを確認しました。

成果と学び

  • Terraform で LXD コンテナを複数管理する方法を習得
  • 単一構成から複数構成への移行と、状態管理（terraform state rm）の重要性を理解
  • コンテナごとの Web サーバー構築と、ホストからのポートフォワード設定を実践
  • ローカル環境で EC2 風のインフラ構成（複数インスタンス＋Web サーバー）を再現

このプロジェクトを通じて、クラウドインフラの概念をローカル環境で具体的に体験し、 Infrastructure as Code（IaC）とコンテナ仮想化の基礎を実践的に身につけました。
