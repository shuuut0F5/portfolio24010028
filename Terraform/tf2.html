Terraform × LXD で「完全無料 EC2 管理体験」を構築した記録

クラウドを使わずに、EC2 と同じインフラ管理体験を再現した技術プロジェクト

プロジェクト概要

AWS EC2 を使わずに、完全無料で EC2 と同じ管理体験を再現することを目的に、 Terraform と LXD を組み合わせてインフラ構築を行った。 途中で複数のエラーに遭遇したが、それらを一つずつ解決しながら最終的に Terraform でコンテナを作成・起動・削除できる環境を完成させた。

タイムライン（挑戦と解決の記録）

成功

Terraform の動作確認

terraform -version
which terraform
つまずき

VirtualBox プロバイダーが非公式で init が失敗

公式プロバイダーが存在しないため、Terraform Registry から取得できず。

→ LXD に切り替える方針へ変更

成功

LXD のインストールと初期化

sudo apt install -y lxd
sudo lxd init

ストレージプール名が重複していたため、新しい名前 default2 を設定。

成功

Terraform 設定ファイル vm.tf を作成

resource "lxd_container" "test" {
  name  = "terraform-test"
  image = "ubuntu:22.04"
}
成功

terraform init（プロバイダー取得）

terraform init
つまずき

権限エラー：LXD ソケットにアクセスできない

permission denied: unix.socket

解決

sudo usermod -aG lxd siwuser
sudo reboot
つまずき

コンテナ名の重複エラー

This "instances" entry already exists

解決

lxc delete terraform-test --force
成功

terraform apply（コンテナ作成成功）

Apply complete! Resources: 1 added

EC2 と同じ操作が可能になった

インスタンス一覧

lxc list

インスタンスへログイン（EC2 の SSH と同じ）

lxc exec terraform-test -- bash

インスタンス削除（EC2 terminate と同じ）

terraform destroy
lxc delete terraform-test --force

最終成果

Terraform と LXD を組み合わせることで、クラウドを使わずに EC2 と同じインフラ管理体験を完全無料で再現する環境を構築した。 これはクラウドインフラの学習や IaC の理解に大きく役立つ成果となった。
