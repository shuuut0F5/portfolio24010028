ngrok によるローカル Web インフラ公開手順

作成者：shuto — VPS 不要でローカル環境を安全に外部公開する方法

概要

このページでは、ローカル環境で構築した Web サーバー（LXD / Docker / Nginx / PHP / MySQL など）を ngrok を使って外部公開する最短手順をまとめています。 VPS やルーター設定が不要で、誰でも安全に公開できます。

ngrok を使えるようにする最短手順（3分）

1. 無料アカウントを作成

以下の公式サイトでメール登録するだけで OK。

https://dashboard.ngrok.com/signup

2. authtoken を取得

ログイン後、以下のページに自分専用のトークンが表示されます。

https://dashboard.ngrok.com/get-started/your-authtoken

3. Ubuntu に authtoken を登録

コピーしたトークンを Ubuntu に登録します。

ngrok config add-authtoken <あなたのトークン>

4. 公開したいポートをトンネルする

例：LXD / HAProxy（3000）を公開する場合

ngrok http 3000

例：Docker / Nginx（3001）を公開する場合

ngrok http 3001

実行すると以下のような URL が発行されます。

https://xxxxx.ngrok-free.dev/

この URL をブラウザで開けば、ローカルの Web サイトが外部公開されます。

公開できる構成例（shuto の環境）

  • LXD / HAProxy → 3000
  • Docker / Nginx → 3001
  • PHP-FPM → 9000（内部）
  • MySQL → 3306（内部）
  • Redis → 6379（内部）

ポイント

  • VPS 不要で外部公開できる
  • ルーターのポート開放も不要
  • 安全にローカル環境を公開できる
  • 複数ポートを同時に公開可能（3000 / 3001）
