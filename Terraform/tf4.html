Terraform × LXD による複数コンテナ Web サーバー構築

作成者：shuto — ローカル環境でクラウド構成を再現した技術プロジェクト

概要

このプロジェクトでは、Terraform と LXD を組み合わせて、 複数の Ubuntu コンテナを Web サーバーとして構築し、ロードバランサーで束ねる環境 をローカルで再現しました。 AWS EC2 × Auto Scaling × ELB の基礎構成を、クラウドを使わずに自分の PC 上で構築しています。

使用技術

  • Terraform（Infrastructure as Code）
  • LXD（軽量コンテナ仮想化）
  • Ubuntu 22.04 コンテナ
  • nginx（Web サーバー）
  • HAProxy（ロードバランサー）

構成図


┌──────────────┐
│   HAProxy LB   │  ← http://localhost:8080
└──────┬─────────┘
       │ round-robin
 ┌─────┴─────┐
 │           │
▼           ▼
web-1   web-2   web-3
:8081   :8082   :8083
(This is web-1 / 2 / 3)

Terraform による複数コンテナ構築

resource "lxd_container" "web" {
  count = 3
  name  = "web-${count.index + 1}"
  image = "ubuntu:22.04"
}

この設定により、web-1 / web-2 / web-3 の 3 台が自動作成されます。

nginx のインストール（各コンテナ）

sudo apt update
sudo apt install -y nginx

Web ページの変更（動作確認用）

# web-1
echo "This is web-1" | sudo tee /var/www/html/index.html

# web-2
echo "This is web-2" | sudo tee /var/www/html/index.html

# web-3
echo "This is web-3" | sudo tee /var/www/html/index.html

ホスト側からのポートフォワード設定

lxc config device add web-1 http proxy listen=tcp:0.0.0.0:8081 connect=tcp:127.0.0.1:80
lxc config device add web-2 http proxy listen=tcp:0.0.0.0:8082 connect=tcp:127.0.0.1:80
lxc config device add web-3 http proxy listen=tcp:0.0.0.0:8083 connect=tcp:127.0.0.1:80

HAProxy によるロードバランシング

frontend http_front
    bind *:8080
    mode http
    default_backend http_back

backend http_back
    mode http
    balance roundrobin
    server web1 127.0.0.1:8081 check
    server web2 127.0.0.1:8082 check
    server web3 127.0.0.1:8083 check

動作確認

curl http://localhost:8080
# → This is web-1
# → This is web-2
# → This is web-3（リロードで切り替わる）

リロードするたびに表示が切り替わることで、 ロードバランサーが 3 台の Web サーバーに正しく振り分けている ことを確認しました。

成果

  • Terraform による複数コンテナの自動構築を実現
  • nginx を用いた Web サーバー群を構築
  • LXD のプロキシ機能でホストからアクセス可能に
  • HAProxy によるロードバランシングを実装
  • クラウド構成（EC2 × ELB）をローカルで再現

このプロジェクトを通じて、コンテナ仮想化・IaC・ロードバランシングなど、 インフラ構築の基礎を実践的に習得しました。
